# 🎨 Command: /ui (UI Engineering)

## 🎯 Purpose
Активация режима проектирования интерфейсов проекта.

## 🛠 Workflow
1. **Trigger**: Пользователь вводит `/ui [описание компонента или экрана]`.
2. **Analysis**: Агент анализирует запрос на соответствие `SPECIFICATION.md` и регламенту `.rules/ui-ux.md`.
3. **Execution**: Проектирование и реализация компонента в рамках текущего стека проекта.
4. **Integration**: Предложение кода компонента с настройкой стилей и анимаций согласно регламенту.

## 📜 Constraints
- **Fidelity**: Любой сгенерированный через `/ui` код должен строго следовать сетке 8pt и цветовым токенам из `SPECIFICATION.md`.
- **Verification**: После вставки компонента агент обязан предложить запуск Playwright для визуальной проверки.

## ⌨️ Example Usage
- `/ui создать дашборд задач`.
- `/ui найти анимированную карточку для списка резидентов`.
